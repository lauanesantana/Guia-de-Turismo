# ☁️ Cloud Dreams – Guia de Turismo

Aplicativo Android de **guia de turismo** desenvolvido em **Kotlin** para a disciplina de Desenvolvimento Mobile do curso de **Análise e Desenvolvimento de Sistemas – IFSP Campus Araraquara**.

A ideia do app é ajudar o usuário a conhecer destinos de viagem pelo mundo de forma simples e visual, reunindo em um só lugar as informações principais de cada local e um jeito rápido de falar com a agência.

> 🚧 Projeto em desenvolvimento: as funcionalidades podem mudar ao longo do semestre.

---

## ✨ Funcionalidades

- Menu de destinos de viagem com imagens
- Detalhes de cada destino: pacote, hotel e telefone
- Contato rápido por telefone, mapa e e-mail

---

## ▶️ Como executar

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no **Android Studio**.
3. Aguarde o **Gradle Sync** terminar e rode o app em um emulador ou celular.
